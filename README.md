--Justificacion Tecnica--

El presente rediseño optimiza la experiencia de usuario (UX/UI), la maquetación y la accesibilidad del Portal Docente de la Universidad Evangélica de El Salvador (UEES), transformando una interfaz desorganizada en un entorno moderno, limpio y funcional

Estructura y Maquetación: La interfaz original presentaba una disposición rígida y botones de acción agrupados verticalmente a la derecha sin jerarquía clara. El nuevo código implementa una maquetación basada en CSS Flexbox, organizando el espacio de trabajo de forma intuitiva, con una barra lateral dedicada y un área central despejada para la gestión académica

Jerarquía Visual y Accesibilidad: Se reemplaza el apilamiento masivo de botones azules por una separación lógica entre las acciones de gestión directa (Listar Estudiantes, Guardar) y las opciones administrativas (Manual de usuario, Cambio de contraseña)

Identidad Institucional: Se mantienen y modernizan los elementos distintivos de la marca mediante estilos actualizados (styles.css), incorporando variables CSS y recortes geométricos (clip-path) para refrescar los banners decorativos sin perder el reconocimiento visual de la universidad
